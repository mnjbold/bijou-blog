What You'll Build

An automated news curator that monitors RSS feeds from your favorite sources, uses an LLM to score and summarize each article for relevance, then delivers a personalized daily digest to your inbox or Telegram. The whole system runs on a schedule in n8n — zero servers to manage, and you can tweak the AI prompt to match exactly what you care about.

Why This Matters

Information overload is the silent productivity killer. Founders, operators, and investors spend 30–60 minutes a day skimming headlines just to stay current. Most of what they read is noise — press releases, marketing fluff, recycled news. A human-curated newsletter costs time or money. An AI-powered curator runs on autopilot, surfaces the 3–5 articles per day that actually matter to you, and costs about $1–3/month in API fees. Over a year, that's 200+ hours of regained focus for the price of a coffee subscription.

What You Need

  • n8n instance — self-hosted via Docker (docker run -it --rm --name n8n -p 5678:5678 n8nio/n8n) or use n8n.cloud (free tier works)
  • OpenAI API key — or any LLM provider (Anthropic, Google Gemini, local via Ollama). Budget ~$2/month
  • RSS feeds — pick 3–10 sources you actually read (HN, TechCrunch, arXiv, industry blogs, etc.)
  • Delivery channel — Telegram bot (free) or email (SMTP credentials)
  • ~2 hours — most of it is tuning the AI prompt to your taste

The Blueprint

Step 1: Set Up Your n8n Workflow Canvas

Create a new workflow in n8n. We'll build it top-to-bottom: Schedule → RSS Fetch → Parse → AI Filter → Format → Deliver.

Start with a Schedule trigger node. Set it to run once daily — I recommend 7:00 AM so your digest is waiting when you start your day. Cron expression: 0 7 *.

Step 2: Add Your RSS Feed Nodes

Add an RSS Feed Read node for each source. n8n's built-in RSS node is simple:

| Parameter | Value |

|-----------|-------|

| URL | https://news.ycombinator.com/rss |

| Options | Check "Ignore Failures" |

Repeat for each feed. Then merge them with an Item Lists > Merge node set to "Combine" mode. This gives you a single list of articles from all sources.

Pro tip: Don't add too many feeds at once. Start with 3–5 high-quality sources. You can always add more later. The AI filter is good, but garbage in = garbage out.

Step 3: Deduplicate Articles

Articles often appear across multiple feeds. Add a Data Transformation > Remove Duplicates node. Set the field to link or guid. This ensures you never see the same story twice.

Step 4: Score Every Article with AI

This is the magic step. Add an AI > OpenAI node (or any LLM node) and configure a chat completion:


System: You are a news curator. Given an article title and description, 
rate its relevance on a scale of 1-10 for a [YOUR_PROFILE] reader.

Context to consider:
- Prefer articles about: AI, automation, startups, productivity tools
- Prefer articles with actionable insights or technical depth
- Discount articles that are: press releases, generic listicles, paid promotions

Respond with ONLY a JSON object:
{"score": <1-10>, "reason": "<one sentence>", "summary": "<1-line summary>"}

For the User Message template, use:


Title: {{ $json.title }}
Description: {{ $json.description }}
Source: {{ $json.sourceName }}

This is where you tune for your interests. I run one for "AI engineering" and another for "Southeast Asian startups" — the only difference is the system prompt.

Step 5: Filter and Sort the Results

Add a Data Transformation > Filter node. Keep only articles where:


{{ $json.score >= 7 }}

Then add a Sort node, sorting by output.score in descending order.

Finally, add a Limit node set to 5–7 items. You don't need more than that — if the AI couldn't find 5 great articles today, don't pad the list.

Step 6: Format Your Digest

Add a Code node with a simple JavaScript function to build the output:


const items = $input.all();
let digest = `📰 *Your Daily AI Brief* — ${new Date().toLocaleDateString()}\n\n`;

items.forEach((item, i) => {
  digest += `*${i+1}. ${item.json.title}*\n`;
  digest += `_Score: ${item.json.score}/10_ — ${item.json.summary}\n`;
  digest += `[Read more](${item.json.link})\n\n`;
});

digest += `---\n🤖 Curated by AI. ${items.length} articles from ${new Set(items.map(i => i.json.sourceName)).size} sources.`;

return [{ json: { digest } }];

Step 7: Deliver the Digest

For Telegram, add a Telegram > Send Message node. Set:

  • Chat ID: your bot chat ID
  • Text: {{ $json.digest }}
  • Parse Mode: Markdown

For Email, add an Email > Send an Email node. Use SMTP credentials (Gmail app passwords work fine). Set the body to your formatted digest with a simple HTML wrapper.

![Workflow diagram: Schedule → RSS Reader × 3 → Merge → Deduplicate → OpenAI Score → Filter → Sort → Limit → Code Format → Telegram Send]

Step 8: Test and Iterate

Run the workflow manually. Check the output at each node:

1. Are you getting articles from all feeds?

2. Is the AI scoring reasonable?

3. Does the digest look good in your delivery channel?

Tune the system prompt based on what you see. If the AI is too generous, raise the threshold to 8. If it's missing gems, adjust the "Prefer articles about" list.

The n8n Workflow JSON

Here's a minimal version you can import directly:


{
  "name": "AI News Curator",
  "nodes": [
    {
      "name": "Schedule",
      "type": "n8n-nodes-base.scheduleTrigger",
      "parameters": { "rule": { "interval": [ { "field": "cronExpression", "expression": "0 7 * * *" } ] } }
    },
    {
      "name": "HN Feed",
      "type": "n8n-nodes-base.rssFeedRead",
      "parameters": { "url": "https://news.ycombinator.com/rss" }
    },
    {
      "name": "Merge",
      "type": "n8n-nodes-base.merge",
      "parameters": { "mode": "combine" }
    },
    {
      "name": "AI Score",
      "type": "@n8n/n8n-nodes-langchain.toolChatCompletion",
      "parameters": {
        "systemMessage": "You are a news curator. Rate relevance 1-10 for a tech founder interested in AI, automation, and startups. Respond with JSON: {score, reason, summary}",
        "promptType": "define",
        "text": "Title: {{ $json.title }}\nDescription: {{ $json.description }}"
      }
    },
    {
      "name": "Filter",
      "type": "n8n-nodes-base.filter",
      "parameters": { "conditions": { "string": [ { "value1": "={{ $json.score }}", "operation": "numberGreaterEqual", "value2": 7 } ] } }
    },
    {
      "name": "Limit",
      "type": "n8n-nodes-base.limit",
      "parameters": { "maxItems": 5 }
    },
    {
      "name": "Format Digest",
      "type": "n8n-nodes-base.code",
      "parameters": { "jsCode": "const items = $input.all();\nlet digest = `📰 *Daily Brief* — ${new Date().toLocaleDateString()}\\n\\n`;\nitems.forEach((item, i) => {\n  digest += `*${i+1}. ${item.json.title}*\\n`;\n  digest += `_Score: ${item.json.score}/10_ — ${item.json.summary}\\n`;\n  digest += `[Read](${item.json.link})\\n\\n`;\n});\nreturn [{ json: { digest } }];" }
    },
    {
      "name": "Telegram",
      "type": "n8n-nodes-base.telegram",
      "parameters": { "chatId": "YOUR_CHAT_ID", "text": "={{ $json.digest }}", "additionalFields": { "parse_mode": "Markdown" } }
    }
  ],
  "connections": {
    "Schedule": { "main": [ [ { "node": "HN Feed" } ] ] },
    "HN Feed": { "main": [ [ { "node": "Merge" } ] ] },
    "Merge": { "main": [ [ { "node": "AI Score" } ] ] },
    "AI Score": { "main": [ [ { "node": "Filter" } ] ] },
    "Filter": { "main": [ [ { "node": "Limit" } ] ] },
    "Limit": { "main": [ [ { "node": "Format Digest" } ] ] },
    "Format Digest": { "main": [ [ { "node": "Telegram" } ] ] }
  }
}

Tips & Gotchas

  • Token limits bite. If you have 50+ articles per run, you'll hit context limits. Add a "Sample" node set to 30 items before the AI node, or batch-process in groups of 10.
  • Rate limits on RSS feeds. Some sites (Substack, Medium) throttle rapid requests. Add a "Wait" node (30–60s) between RSS reads if you notice failures.
  • Prompt drift. Over weeks, the AI's scoring may shift as models update. Re-check your digest quality monthly. Add a "reason" field to each score so you can see why something was included.
  • No news is good news. If the AI filters everything out on a slow day, your Telegram won't fire. That's fine — don't force articles in. Add a "Set" node before the delivery node to check if items.length > 0.
  • Self-hosted n8n memory. The free n8n.cloud tier limits execution history to 7 days. Self-host with Docker if you want longer retention — it's one command.
  • Costs. OpenAI's gpt-4o-mini costs $0.15/1M input tokens. At ~500 tokens per article × 30 articles/day, that's ~$0.07/month. Even gpt-4o is under $2/month at this volume.

Next Steps

This blueprint is a foundation. Here's how to level it up:

1. Add a web feed. Instead of just Telegram, generate an HTML page and deploy it to Netlify automatically. You've just built your own curated newsletter.

2. Multi-LLM routing. Use a simple model (gpt-4o-mini) for initial scoring, then pass the top 3 to a stronger model (Claude Sonnet or Gemini) for deep summaries.

3. User feedback loop. Add a Telegram inline button with thumbs-up/thumbs-down. Log responses and feed them back into the prompt as few-shot examples.

4. Keyword alerts. Add a parallel branch that checks every article (no score filter) for your specific keywords — competitor names, funding rounds, tech stacks — and alerts you immediately via SMS.

5. Weekly trends report. Cache scores over a week and run a separate weekend workflow that builds a "What mattered this week" summary using a second LLM pass.

The beautiful thing about this setup: the hard part isn't the technology — it's knowing what you care about. The AI is just a filter for your taste. Define that clearly, and this system will save you more time than almost any other automation you can build.
