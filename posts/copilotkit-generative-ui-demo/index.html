What Is Generative UI?

Most AI chatbots produce text. You ask a question, they type back. That's the classic chat interface — a single conversation thread where everything happens in words.

Generative UI flips this. Instead of responding with text, the AI generates live React components — interactive widgets, data visualizations, forms — right inside the chat. The agent doesn't just tell you it found a weather pattern; it renders a weather card with charts. It doesn't just describe a form; it displays one you can fill out immediately.

This is the paradigm shift that CopilotKit enables. And I built a demo to show exactly how it works.

Three Interaction Modes

The demo showcases three ways generative UI can work:

1. Controlled Generative UI (AG-UI)

The agent has a predefined set of React components it can choose to render. When you ask for a weather report, it renders a WeatherCard component — not just text. The card is live, styled, and interactive. This is the "agent chooses from a toolkit" pattern.

// Agent calls this tool → CopilotKit renders the component
const weatherTool = {
  name: "show_weather",
  component: WeatherCard,
  handler: async (args) => fetchWeather(args.city)
};

2. Declarative Generative UI (A2UI)

The agent outputs JSON structured data, and CopilotKit's A2UI renderer automatically turns it into UI cards. The agent doesn't know about React — it just outputs structured data. The frontend handles the rendering.

// Agent returns this JSON → frontend renders a card
{
  "type": "weather_card",
  "city": "Kuala Lumpur",
  "temperature": 33,
  "condition": "Thunderstorms",
  "humidity": "82%"
}

3. Open-Ended Chat

When the agent doesn't need to render a component, it falls back to natural conversation. This keeps the interface flexible — you can ask it anything, even without triggering a UI component.

Built with CopilotKit + MiMo API

The demo runs on CopilotKit — an open-source framework for building in-app AI copilots with generative UI capabilities. The runtime connects to the MiMo API (Xiaomi's LLM endpoint) as the underlying model provider.

  • Frontend: React 18 + Vite + TypeScript
  • AI Runtime: @copilotkit/runtime with custom MiMo API integration
  • Components: @copilotkit/react-ui sidebar + @copilotkit/a2ui-renderer for declarative rendering
  • Styling: Custom Bijou theme — black (#0a0a0a), gold (#FFD700), cyan (#00BFFF)

Why This Matters

The chat interface hasn't changed meaningfully in decades. Generative UI represents the first real evolution — AI that doesn't just talk back but builds interfaces on the fly. For startups building AI products, this means:

  1. Higher engagement — users interact visually, not just through text
  2. Faster comprehension — a card with key metrics beats a paragraph every time
  3. Richer interactions — forms, charts, and data visualizations inside the chat flow

Try the demo above. Ask it for the weather in Kuala Lumpur, or just have a conversation. Watch how it decides when to render a component versus when to respond with text.
